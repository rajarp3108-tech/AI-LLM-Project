# AI Officer Copilot Frontend

This frontend preserves a clean, professional interface suited to any workflow, while adding:
- saved multi-topic chats
- visible Socket.IO streaming
- optional per-chat RAG uploads
- reusable RAG sources across chats
- per-topic tasks
- rename/delete chat actions
- real backend email/password authentication

## Run
```powershell
Copy-Item .env.example .env
npm install
npm run dev
```
Open `http://localhost:5173`.
